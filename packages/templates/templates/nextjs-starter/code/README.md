# nextjs-starter

A minimal Next.js starter: App Router, TypeScript, and Tailwind CSS. No extra
dependencies, no example CRUD screens — just enough to open a sandbox and start
building.

```bash
npm ci
npm run dev
```

Run commands from this project's root. Open `http://localhost:3000` and edit
[app/page.tsx](app/page.tsx). Shared layout and styling live in `app/layout.tsx`
and `app/globals.css`.

Use `npm run build` to create the production build, then `npm run start` to serve it.
