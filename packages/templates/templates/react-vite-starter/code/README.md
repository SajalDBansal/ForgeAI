# react-vite-starter

A lightweight React app with Vite and TypeScript.

```bash
npm ci
npm run dev -- --host 0.0.0.0 --port 5173
```

Run from this project's root and open `http://localhost:5173`. Start editing
[src/App.tsx](src/App.tsx); [src/main.tsx](src/main.tsx) mounts the React app.

`npm run build` typechecks and writes a production bundle to `dist/`.
`npm run preview` serves that build for local inspection.
